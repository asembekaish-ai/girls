# Tir Game – 2D ойын

Команда: **girls**. pygame-ce кітапханасымен жазылған 2D «Тир» ойыны.

## Ойын туралы

Ойыншы төменде жүріп, жоғарыдағы қозғалатын нысаналарды атады. Нысанаға тиген сайын 1 ұпай беріледі, тиген нысана жойылып, орнына жаңасы пайда болады.

- **Жеңіс:** 60 секунд біткенше 20 ұпай жинау.
- **Жеңіліс:** 20 ұпай жиналмай, уақыт бітті.
- **Қайта бастау:** `R` пернесі.

## Іске қосу

```
pip install pygame-ce
python main.py
```

Ескерту: `pygame` және `pygame-ce` бір уақытта орнатылмауы керек.

## Пернелер

| Әрекет | Перне |
|---|---|
| Солға жүру | ← |
| Оңға жүру | → |
| Оқ ату | SPACE |
| Қайта бастау | R |

## Файлдар және кім қай класты жазды

| Файл | Класс | Мұрагерлік | Авторы |
|---|---|---|---|
| game_object.py | GameObject | ата-ана класы (x, y, size, update, draw) | команда |
| player.py | Player | GameObject-тен; update, draw қайта анықталған | Асембек Айша |
| target.py | Target | GameObject-тен; update, draw, on_hit қайта анықталған | Рыстанова Мерей |
| bullet.py | Bullet | GameObject-тен; update, draw қайта анықталған | Жубатканова Назым |
| score.py | Score | ұпай санайды | Жубатканова Назым |
| game.py | Game | командалық класс | команда |
| main.py | – | ойынды іске қосады | команда |
